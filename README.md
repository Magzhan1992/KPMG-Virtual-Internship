# KPMG-
Отчет

Задача: Провести комплексный анализ клиентской базы (Sprocket Central Pty Ltd) за 2017 год, выявить приоритетные сегменты, оценить потенциал для роста и собрать всю аналитику в единый наглядный дашборд.

Моя работа в Проекте: Разработал интерактивный 7-страничный аналитический дашборд.

Рассчитал ключевые метрики (выручка, прибыль, рентабельность, средний чек).

Провел RFM-сегментацию для выделения самых ценных клиентов (Champions) и клиентов в зоне риска (At risk).

Проанализировал демографию (пол, возраст) и географию (штаты) клиентов.

Оценил вклад брендов и продуктовых линеек в общую прибыль.

Выявил и структурировал проблемы качества исходных данных (пропуски, дубликаты, отмененные заказы).

Добавил интерактивную фильтрацию по регионам для быстрой оценки срезов.

Инструменты: HTML5, CSS3, JavaScript (включая встроенные SVG-графики для визуализации данных), Excel (для анализа исходных данных и QA).

Результат:

Создан интерактивный дашборд, который позволяет быстро оценить состояние базы (4 000 клиентов, выручка ~21,9 млн) и увидеть, что 578 клиентов-«чемпионов» приносят 2,8 млн прибыли, а 753 клиента находятся в зоне риска (потенциал для win-back кампаний).

Выявлены скрытые риски: 179 отмененных заказов и 197 транзакций с пропущенной себестоимостью, искажающие чистую прибыль.

Сделаны выводы о необходимости очистки данных (неуникальные product_id, аномальные даты рождения) перед построением будущих прогнозных моделей.
